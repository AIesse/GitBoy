笔记软件最大的风险不是不好用，而是用了三年之后发现内容搬不走。数据库加密、附件散在缓存目录、导出功能只给你一堆带乱码的 HTML——想换工具时，几百篇笔记变成一笔沉没成本。另一条路是直接用 Markdown 文件，代价通常是要忍受 Electron 的体积、插件配置和一堆需要自己维护的扩展。

妙言走的是第三条：原生 macOS 应用，笔记就是你指定文件夹里的普通 `.md` 文件，打开就是文件系统本身，没有导入导出这一层。

**妙言（MiaoYan）是一个用 Swift 6 写的原生 Markdown 笔记本**，MIT 许可证，支持 macOS 12.0 及以上。它把文件夹、笔记列表和编辑器分成三栏，提供编辑、预览、分栏三种查看方式，内置 LaTeX 公式、Mermaid 与 PlantUML 图表、`[[双链]]`、版本历史、一键自动排版和基于 Reveal.js 的 PPT 演示模式。同一套笔记也能在 iPhone 和 iPad 上打开。

> 本文依据妙言官方 GitHub 仓库的 README（中英文版）、`ARCHITECTURE.md`、内置的《介绍妙言》与《妙言 PPT》指南、GitHub Releases 的版本说明，以及官网与 App Store 页面整理。数据核对时间为 2026-11-26：8,833 星、19 位贡献者、2,322 次提交，最新版本 v4.12.0（2026-11-25 发布）。本文属于资料型评价，没有对安装包做逐项实机测试，界面截图取自官网 `miaoyan.app/assets/shots`。

## 一、核心功能

### 1. 笔记就是文件夹里的 .md 文件

妙言没有自己的数据库。你在设置里指定一个文件夹作为存储位置，它把这个文件夹下的子目录当分类、`.md` 文件当笔记，三栏界面只是这层文件系统的投影。分类对应真实文件夹，重命名分类就是重命名文件夹，用 Finder 或任何编辑器改动，妙言刷新后看到的就是改后的样子。

附件的处理也落在文件系统里：按 `ARCHITECTURE.md` 的说明，笔记同级的 `i/` 目录放内联图片，`files/` 目录放其他附件。这意味着你把整个文件夹拷到另一台机器，图片和附件跟着走，不会出现「正文在、图全挂」的情况。

同步不由妙言负责。它不登录 WebDAV，也不接管网盘账号，跨设备同步交给 iCloud 云盘、坚果云、Dropbox 这些客户端。官方在 README 里给了具体做法：在云盘同步目录下建一个 `MiaoYan` 文件夹，按 `⌘,` 把存储位置指过去。妙言会在切换目录前检查读写权限，目录不可用时保留原路径，而不是把它报成「云同步失败」。

![三栏布局：左侧是文件夹分类，中间是笔记列表，右侧是 Markdown 原文](/GitBoy/images/miaoyan-markdown-notes-review/04-edit.jpg)

这种设计的好处是可逆：哪天不想用了，文件夹原样留在那儿，任何 Markdown 工具都能接手。代价也清楚——它没有数据库索引，几万篇笔记的检索要靠文件系统和自己的索引逻辑，而不是 SQL。

### 2. 编辑、预览、分栏：三种看法，同一个文件

妙言不做 Typora 那种所见即所得。官方在 README 里把理由写得很直接：纯 Swift 实现所见即所得很重，也难保证稳定，分栏模式能让人专心看 Markdown 原文，旁边同步给出排版结果。

三种模式对应三个快捷键：`⌘3` 在源码与排版之间切换，`⌘\` 打开左右分栏，`⌘4` 进入演示模式。分栏是它的主打形态，左边写、右边即时渲染，官方声称双向滚动同步做到 60fps。

![分栏模式：左边是 Markdown 原文，右边实时渲染出 Mermaid 流程图与代码块](/GitBoy/images/miaoyan-markdown-notes-review/02-split.jpg)

渲染链路在架构文档里写得很清楚：笔记内容经 `swift-cmark-gfm` 转成 HTML，交给一个 `WKWebView` 加载本地 `DownView.bundle` 显示；后续编辑不整页重载，而是做增量 DOM 更新。这也是分栏能跟得上打字速度的原因。

预览模式则是纯读者视角：长文按书的版式排版，支持表格、脚注、任务清单、图片和引用，任务清单的复选框在预览里可以直接点。导出方面，v4.10.0 的发布说明提到可以导出 PNG、PDF 和 HTML。

![预览模式：图片、链接和段落排版按阅读样式呈现](/GitBoy/images/miaoyan-markdown-notes-review/03-preview.jpg)

### 3. 公式、图表、双链和 PPT，都塞进同一个编辑器

妙言的 Markdown 支持范围比「能写标题和列表」要宽：GitHub Flavored Markdown 打底，往上叠加 LaTeX 行内与块级公式、Mermaid 流程图、PlantUML、Markmap 思维导图，以及 `[[笔记名]]` 形式的双链。官网写明双链带反向链接，输入 `[[Note|label]]` 可以给链接起别名。

写作时的效率主要来自 Tab 片段：在正文里输入 `/` 开头的指令再按 Tab，模板直接展开。内置的有 `/time`、`/table`、`/img`、`/video`、`/markmap`、`/mermaid`、`/plantuml`、`/fold`、`/task`。粘进来一段没格式的纯文本，按 `⇧⌘L` 触发自动排版，标题、列表和空行会被重新整理。

PPT 模式是它比较特别的一块。任何包含 `---` 分隔符的文档都能按 `⌥⌘P` 进入演示，底层是 Reveal.js，所以 Reveal 的配置项基本都能用：文档开头写一段 HTML 注释就能改切换动画、页码格式、是否显示控制条；`<!-- .slide: data-background="#F8CB9E" -->` 换单页背景；`<!-- .element: class="fragment" -->` 控制元素逐个出现；代码块还能用 `swift [1|2-4|5-7]` 这种写法做逐行高亮。对经常要把笔记直接讲给别人听的人，这比「复制到 Keynote 重排一遍」省事。

预览里的长文导航靠大纲：按 `⌘5` 唤出目录，文档里有两个以上标题时自动生成。

### 4. 版本历史、表格与清理：近期迭代都在补细节

看最近三个版本的发布说明，能判断这个项目现在在忙什么。v4.12.0（2026-11-25）做了几件事：表格的竖线对齐更淡、新增表格菜单可以直接增删行列；版本历史会显示每个版本改了多少行并高亮改动处；分栏模式下即使笔记以图片或表格结尾，预览也能和编辑区一起滚到底；清理未被引用的附件时更保守，子目录和废纸篓里笔记用到的文件、只在 iCloud 上还没下载的笔记、以及刚添加的文件都不会被删掉。

版本历史按笔记保存，架构文档写明存放在 `~/Library/Application Support/com.tw93.miaoyan/Versions/<路径哈希>/`，重命名、移动文件夹和移入废纸篓时会跟着走。这里有个容易忽略的点：它不在笔记文件夹里，所以不会随 iCloud 文件夹同步到别的设备。

删除行为分两档：笔记进笔记库自己的 `Trash` 文件夹，文件夹和图片走系统废纸篓。App Store 页面的 iOS 端说明还提到，笔记移入废纸篓后五秒内可以撤销。

### 5. 命令行、Agent Skill，以及 iPhone 那一端

随应用提供的 `miao` 命令行把常用操作搬到了终端：

```bash
miao open <标题|路径>    # 打开笔记或文件夹
miao new <标题> [内容]   # 创建新笔记
miao search <关键词>     # 在终端搜索笔记
miao list [目录]         # 列出一级目录，或列出指定目录下的 Markdown
miao cat <标题|路径>     # 输出笔记内容
miao update              # 更新 CLI
```

安装用官方的一行脚本，仓库里还有一份 agent skill，`npx skills add tw93/MiaoYan/skills/miaoyan -g` 装完之后，Claude Code 这类工具就能知道妙言的语法、附件、PPT 写法和 CLI 用法。这个思路和很多笔记应用不同：它没有等第三方做集成，而是自己把「给 agent 看的说明书」放进了仓库。

![深色模式下的编辑界面，Swift 代码块带语法高亮](/GitBoy/images/miaoyan-markdown-notes-review/05-dark.jpg)

iPhone 和 iPad 版把同一个文件夹搬到了触屏上。它打开同一个 iCloud 云盘文件夹，界面按触屏重排过：iPad 上笔记列表和正文并排，键盘上方多了一条插入栏，可以加待办、列表、链接和附件；阅读时支持衬线、黑体、圆体三种字体和三档字号；还能把笔记分享成图片，或者用小组件、Siri、快捷指令直接新建笔记。

![iPhone 上的阅读视图，同一篇笔记按手机版式重排](/GitBoy/images/miaoyan-markdown-notes-review/06-iphone.jpg)

需要注意开源边界：Mac 端是 MIT 开源，代码在本仓库；iPhone 和 iPad 端不开源，按架构文档的说明，App Store 的打包和 iOS 应用放在私有的 `tw93/MiaoYan-Pro` 仓库里，合并本仓库的 `main` 后发布。

## 二、适合哪些使用场景？

- **笔记必须能以文件形式带走：** 不接受数据库、不接受私有格式，希望十年后还能用任意编辑器打开。
- **Mac 上想要一个轻量的 Markdown 写作用具：** 不想为写几百字启动一个 Electron 应用，也不想维护插件和主题。
- **经常写技术文档：** 公式、Mermaid、PlantUML、代码高亮和表格都在内置支持里，不用装扩展。
- **要把笔记直接讲出来：** 用 `---` 分页，`⌥⌘P` 就是一份演示文稿，代码还能逐行高亮。
- **已经在用 iCloud 或坚果云：** 同步交给现成的云盘客户端，妙言只管读写文件。
- **需要手机端接着写：** 愿意为 iOS 端付一次买断费，换取同一套笔记在三种设备上打开。
- **想让 agent 帮忙整理笔记：** 官方提供了 CLI 和 skill，不必自己写适配层。

反过来说，如果你需要双向链接做成知识图谱、需要社区插件生态、需要多人协作和块引用，妙言不是这个方向，Obsidian 或 Logseq 更合适；如果你只想要所见即所得、完全不想看到 Markdown 符号，Typora 那类工具更对路。

## 三、优点与注意事项

**优点**

1. 数据形态最朴素：笔记是 `.md`，附件在 `i/` 与 `files/`，分类是文件夹，随时可以整体搬走。
2. 原生实现，不是网页套壳，官方称比网页套壳更轻；对性能做了分级处理，超长文档自动降级高亮而不是卡死。
3. 功能密度高且都在本地：公式、四类图表、双链、版本历史、自动排版、PPT、导出 PNG/PDF/HTML，不需要插件。
4. 快捷键覆盖完整：`⌘3` 切换、`⌘\` 分栏、`⌘5` 大纲、`⇧⌘L` 排版、`⌥⌘P` 演示、`⌥⌘M` 全局唤起。
5. 更新节奏稳定：v4.9.0 到 v4.12.0 在半个月内连发四个版本，改的多是表格、版本历史、附件清理这类具体问题。
6. 有 CLI 和 agent skill，方便脚本化和自动化。
7. 开源版免费，Mac 端的写作功能与 App Store 版一致，官方 FAQ 明确说明这一点。

**需要留意**

1. Mac 开源版免费，但 iOS/iPadOS 端不开源，且只在 App Store 上以买断形式提供。中国区页面显示 ¥88，一次购买覆盖 Mac、iPhone、iPad，无订阅、无内购；价格会随地区和促销变化，以商店页面为准。
2. 不做所见即所得是明确的设计选择，不是缺陷。习惯 Typora 的人需要适应「看源码 + 看右边」的写法。
3. 没有插件系统。功能边界由作者决定，想要社区扩展只能等版本更新或自己改代码。
4. 同步完全依赖外部云盘。妙言不处理冲突合并，App Store 页面的说明是：另一台设备改了同一篇笔记时会询问保留哪个版本。
5. 版本历史存在本机 `Application Support` 下，不随笔记文件夹同步，换设备看不到另一台的版本记录。
6. 大文档会降级：按架构文档的阈值，总长超过 1MB 或单段超过 64KB 时只做简化高亮，超过 5000 行同样简化。
7. 仓库标签里写着「Obsidian 替代品」「Typora 替代品」，但它的定位更窄——本地文件、原生、够用的内置功能，不是可扩展的知识库平台。
8. 本文没有实机跑过安装包，界面与交互描述全部来自官方截图与文档；性能与稳定性结论也以官方说法为准。

## 四、安装方式

### App Store（三端买断）

Mac、iPhone、iPad 一次购买通用，自动更新：

- 中国区页面：[apps.apple.com/cn/app/miaoyan/id6759252269](https://apps.apple.com/cn/app/miaoyan/id6759252269)
- 系统要求：Mac 端 macOS 12.0 及以上；iPhone / iPad 端 iOS 18.0 或 iPadOS 18.0 及以上

### Homebrew（开源版，免费）

```bash
brew install --cask miaoyan
```

### GitHub Releases（开源版，免费）

到 Releases 页面下载最新的 macOS 安装包，要求 macOS 12.0 及以上：

```bash
open https://github.com/tw93/MiaoYan/releases/latest
```

### 命令行工具

```bash
curl -fsSL https://raw.githubusercontent.com/tw93/MiaoYan/main/scripts/install.sh | bash
```

### Agent Skill（可选）

```bash
npx skills add tw93/MiaoYan/skills/miaoyan -g
```

装完之后第一次打开，妙言会在笔记文件夹里放一份《介绍妙言》指南，里面有一张表格、一份待办清单、一张 Mermaid 图和一条公式，用来演示渲染效果；看完可以从应用内把指南收进废纸篓。

## 五、综合评价

妙言解决的问题很具体：在 Mac 上写 Markdown，想要原生应用的轻快，又不想把笔记交给自己控制不了的数据结构。它的答案是把所有东西都还原成文件——正文是 `.md`，图片在 `i/`，附件在 `files/`，分类是文件夹。围绕这个决定，它把公式、图表、双链、版本历史、PPT 这些通常要靠插件拼出来的能力做成了内置项。

它的取舍也很清楚。不做所见即所得，是因为作者判断 Swift 原生实现太重、不够稳；不做插件系统，是因为不想让人花时间维护扩展；同步不自己做，是因为云盘客户端已经够用。这些决定让它比同类工具窄，但也让它比同类工具稳——一个只有文件和原生控件的应用，出问题的地方本来就少。

真正需要注意的是授权模型：Mac 端 MIT 开源、免费；iOS 端闭源、买断 ¥88。如果你只在 Mac 上写，直接 Homebrew 装开源版就行，功能不缺。如果你需要手机和平板接着写，这个价格买的是一套三端打通的本地文件工作流，不是订阅。

**一句话评价：** 一个把「笔记就是文件」贯彻到底的原生 Markdown 笔记本，适合要轻快写作、又要随时能把整个笔记库搬走的人。
