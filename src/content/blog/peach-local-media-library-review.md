![Peach 影片馆藏：搜索、筛选与海报墙](/images/peach-review/home-wide-20261118-2-1280.webp)

影片文件散落在硬盘、NAS 和网盘里时，找一部片往往要先想起它存在哪个文件夹，再凭文件名猜内容。文件名常常只是一串编号，没有标题、演员、封面和分类，时间一长，库越大越难找。

**Peach** 是一款本地优先的影片刮削与媒体管理工具。它的核心思路很直接：按影片编号识别文件，从多个来源补齐标题、演员、厂牌和封面，把散落的影片整理成一个可以在浏览器里搜索、筛选、播放的本地媒体库，资料和观看记录都保存在本机。

> 本文依据 Peach 官方 GitHub 项目说明、文档与发布信息整理，并结合官方演示站 demo.peach.video 的实测（2026-11-21，未登录），属于资料型使用评价，并非对所有功能进行逐项实机测试。功能状态以官方仓库为准。

## 一、核心功能

### 1. 影片刮削：按编号识别，多来源补齐

Peach 扫描媒体目录后识别影片编号，读取同目录的 NFO 文件，再从多个来源补齐标题、演员、厂牌和封面。来源给出的信息会保留出处与置信度，互相冲突或只有单一来源的会留作待确认资料，不会直接当成定论；人工修改过的内容会被保护起来，来源刷新不会覆盖。

断网时也不影响本地部分：扫描、读取媒体属性、配套文件检查和视频预览照常完成，有 NFO 的作品按 NFO 写入资料、装上本地海报；联网恢复后会自动重试未完成项，补齐外部资料与封面。

### 2. 本地与网盘统一浏览

媒体库可以同时覆盖本地硬盘、SMB 共享、已挂载的网盘和 PikPak。演示站首页左侧提供来源、时长、产地、发行年份、画幅、创作者和内容标签等多维筛选，顶部还有艺人头像墙与厂牌墙，配合排序（评分、观看次数、时长、体积、入库时间等），找片主要靠检索而不是翻文件夹。

![Peach 人物与作品页](/images/peach-review/profile-wide-20261118-2-1280.webp)

### 3. 播放与记录

支持网页播放与外部播放器，含字幕、倍速、旋转、续播和时间轴预览。实测演示站时，详情页本身没有播放按钮，播放入口在首页顶部的“进入播放墙”，是一个深色全屏播放界面，带播放列表、稍后看、进度条和详情入口；演示站的播放入口仅提供演示，不加载视频，实际播放效果需要在自己的部署上验证。

![Peach 播放器](/images/peach-review/play-wide-20261118-2-1280.webp)

### 4. 关注与发现

可以订阅人物与创作者的更新，发现新作品，管理“想要”清单。演示站的关注页会汇总订阅对象的最新作品，相当于给常看的创作者设了一个更新提醒。

![Peach 创作者关注与作品更新](/images/peach-review/follow-wide-20261118-2-1280.webp)

### 5. 馆藏管理与任务中心

提供标签管理、重复文件、多版本与分卷处理；统计页汇总馆藏、存储与观看数据。后台任务可以在任务中心暂停、继续或取消，并查看各任务的 CPU、GPU 与下载活动。需要转码时支持硬件加速（AMD / Intel 用 VAAPI，有 NVIDIA 设备时探测 NVENC），失败会回退软件转码。

![Peach 馆藏、存储与观看统计](/images/peach-review/stats-wide-20261118-2-1280.webp)

## 二、适合哪些使用场景？

- **影片散落在硬盘、NAS 和网盘：** 想统一编目、检索和浏览，而不是在文件夹之间来回翻找。
- **希望元数据自动补齐：** 按编号识别并补全标题、演员、厂牌和封面，不想逐部手动整理。
- **只在本机或局域网使用：** 资料和观看记录保存在本机，不想把媒体库交给第三方云服务。
- **有 NAS 或 VPS：** 想自托管一个媒体库，用浏览器管理。
- **需要按人物、厂牌和标签检索：** 或想订阅创作者更新、维护一份想要清单。

如果只是偶尔看一两部影片、没有整理与编目的需求，系统自带的文件夹加播放器可能已经够用，未必需要额外部署一个服务。

## 三、优点与注意事项

**优点**

1. 免费且开源，采用 AGPL-3.0 许可证；本地优先，数据存本机。
2. 刮削链路比较完整：编号识别、NFO、多来源补齐、人工修改保留、断网后自动重试。
3. 部署方式齐全：Windows 与 macOS 桌面版、Docker / NAS、源码运行，并提供官方演示站，不用安装也能先看界面。
4. 更新非常勤快：最新是 v0.60.0 预发布版（2026-11-20），约四五天一个版本；仓库有 15,223 星，仍在持续维护。
5. 文档很完整：中英双语，部署、来源支持、外部播放器和诊断都有单独说明。

**需要留意**

1. 当前版本仍是预发布（v0.60.0），功能与界面可能继续变化，不应把路线图项目当成已经可用的功能。
2. 桌面安装包未签名，macOS 尚未完成公证，首次安装需要按系统提示放行。
3. 从源码运行要求 Python 3.14+ 与 uv。
4. 刮削依赖第三方站点，部分来源可能遇到 403、限流或需要代理与 Cookie；断网时只剩 NFO 与本地信息。
5. 这是单人自托管应用，没有多人账号；可选的一键更新要挂 Docker socket，等于宿主机 root 权限，只在信任环境启用。
6. 官方要求仅管理自行持有或获授权使用的媒体，并标有 18+ 年龄限制。

## 四、安装方式

### Docker / NAS

1. 在 `compose.yaml` 同目录创建 `.env`，写宿主机媒体目录与 NAS 局域网 IP：

```
PEACH_MEDIA_ROOT=/srv/videos
PEACH_BIND=192.0.2.10
```

2. 运行 `docker compose up -d`。
3. 在浏览器打开 `http://<NAS 局域网 IP>:8900`，在首次设置页设访问密码。Peach 没有初始密码。

注意两点：Compose 默认只绑定 `127.0.0.1`，不改时只有 NAS 本机能打开；数据保存在 `peach-data` 卷，媒体目录默认只读挂载，整理、移动与删除需要明确提供可写挂载。

### 桌面版

1. 打开 [Peach 官方 Releases 页面](https://github.com/peach-mitao/peach/releases)。
2. 下载最新发布的安装包：Windows 有安装版与免安装版，macOS 分 Apple Silicon 与 Intel 两个 DMG。
3. 安装后选择媒体目录，扫描后即可浏览与播放。

### 从源码运行

需要 Git、uv 和 Python 3.14+，步骤见 [官方运行与配置文档](https://github.com/peach-mitao/peach/blob/master/docs/OPERATIONS.md)。

官方项目地址：[github.com/peach-mitao/peach](https://github.com/peach-mitao/peach)

## 五、综合评价

Peach 解决的是一个很具体、却容易被忽略的问题：影片文件散落在各处，文件名只剩编号，找片全靠记忆。它通过编号识别、NFO 读取、多来源补齐和本地海报，把“整理影片”变成一次扫描加一次检索，而不是长期的手动维护。

它最值得关注的地方，并不是功能列表有多长，而是本地优先这条底线：资料、观看记录和封面都在本机，断网也能用本地信息继续浏览；部署方式又足够全，桌面、NAS 与 VPS 都能跑。对有整理需求、又不想把媒体库交给云服务的人，这类工具确实能把找片这件事变简单。

综合来看，如果你手头有一批需要编目的影片，又希望元数据、封面和检索一次到位，Peach 值得列入尝试清单。可以先打开官方演示站看一眼界面，再决定是在 NAS 上用 Docker 跑起来，还是在电脑上装桌面版。不过，安装前应确认自己的部署方式，并留意刮削来源在实际网络环境下的可用情况。

**一句话评价：** 一款定位明确、免费开源、更新极勤的本地优先影片管理工具，适合手头有片库要整理、又想把数据留在本机的人。
